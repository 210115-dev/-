# 物理實驗模型

互動式物理模擬實驗平台，以 HTML5 Canvas 製作，無需安裝任何套件。

## 實驗項目

| 實驗 | 說明 |
|------|------|
| 拋體運動 | 可調整初速度、發射角、重力加速度，即時顯示軌跡、射程、飛行時間 |
| 單擺 | RK4 精確積分，可調整繩長、初始角度、重力，顯示能量柱狀圖 |
| 彈簧振子 | 虎克定律模擬，顯示位移示波器、動能/位能即時數值 |
| 均勻圓周運動 | 顯示速度向量、向心加速度向量、週期時鐘 |

## 使用方式

直接用瀏覽器開啟 `index.html`，即可使用所有模擬功能。

## 技術

- 純 HTML5 / CSS3 / JavaScript（無外部相依）
- HTML5 Canvas 動畫
- RK4 數值積分（單擺、彈簧振子）
